# Task: synthetic per-move arm generator (sprint "Same facts, softer words")

Work only in harness/ (new files) and data/. Python 3 + requests. Do not modify run.py/score.py except to import helpers. No commits.

Goal: from a neutral plain description of an incident, produce controlled rewrites that each apply ONE linguistic move, so any judge shift is attributable to that move.

1. harness/synth.py:
   - Input: data/pairs.jsonl (field plain_neutral; fall back to plain_text) or any jsonl with pair_id + text.
   - Moves (one at a time, plus "all"): euphemism (soften the harm verb/noun: "killed" -> "fatality occurred"), nominalization (verbs to nouns: "the company dumped waste" -> "waste disposal took place"), agent_deletion (passive/agentless: "the employer removed the guard" -> "the guard was removed"), and all_three combined.
   - Rewrites generated by an LLM via OpenAI-compatible API (env BASE_URL/API_KEY/MODEL, same as run.py; --dry-run mock default; --live flag required). Prompt must forbid adding or removing facts and must keep numbers, dates, counts identical.
   - Fact-preservation check: a SECOND call (configurable --checker-model, ideally a different model) extracts a fact list (actor, action, affected, numbers, outcome) from source and rewrite and marks each fact KEPT/LOST/ADDED. Keep a rewrite only if no fact LOST or ADDED except the deliberately hidden agent for agent_deletion (record that as expected). Store checker output.
   - Output data/synthetic.jsonl: {pair_id, move, source_text, rewrite_text, checker: {...}, kept: bool}.
2. harness/synth_to_pairs.py: convert kept rewrites into the run.py pairs format so each move becomes the "soft_text" against the same plain source (pair_id like p01__euphemism), keeping contrast_text from the source pair, so run.py/score.py work unchanged and score.py can be grouped by move suffix.
3. Tests (harness/test_synth.py) with the mock: one move per output, kept filter logic, number preservation check, no network without --live.
Done: `python3 harness/synth.py --dry-run --pairs data/pairs_example.jsonl` and tests pass. Update harness/README.md with commands.
